# Rewrite Landing Page Copy

Write copy the user can paste straight onto their page, with each change tied to a concrete conversion problem.

## Start here

- If a local `landing-pages/<site>/` folder exists for this business, read its `audit.md`, `facts.md`, and `inputs/site-page-text.md` first. Otherwise work directly from the user's pasted copy, URL, or screenshot.
- Follow the voice and anti-slop rules in `../landing-page/references/anti-ai-slop.md` (plain founder voice, zero em dashes, zero deck words, every heading reads alone).

## Method

1. Read the existing copy, offer, and audit. Keep prices, promises, qualifications, and brand language 100% accurate. Never invent results, customers, testimonials, percentages, guarantees, "free", or urgency.
2. Show exact replacements as **Now → Change to**, followed by one short reason. Quote the original text word for word. If the original line does not exist on the page, label the proposed copy as an **Addition** and name where it goes.
3. For a hero / first-screen rewrite, supply the complete **Headline**, **Supporting line**, **Proof line** (from verified facts only), and **Button label** (plus one short "what happens next" line beneath it). Never leave the requested section half-finished.
4. Keep layout instructions separate from the words to paste. Keep lines that are already strong.
5. Never use placeholders like `$X` or `[price]`. If a stronger rewrite needs one missing business fact, deliver the supported version now and name that single gap at the end.

## How to write

- Plain everyday language a real business owner would say out loud.
- Default to under 150 words for a single-section rewrite unless the user asks for full-page copy.
- Lead with the new words and one blunt reason why they convert better. Never turn an uncertain suggestion into a guaranteed lift.
