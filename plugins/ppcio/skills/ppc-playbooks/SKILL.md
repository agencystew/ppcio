# PPC.io First-Principles Knowledge Playbooks

24 deep paid-search knowledge foundations distilled from a decade of managing Google Ads accounts. Load ONLY the 1 or 2 playbooks that directly match the user's question — never read all 24 at once.

## Start here

- If a `landing-pages/*/context.md` file exists in this folder, read it first so your advice fits the exact business, margins, and search intent.
- Pick the 1 or 2 files in `references/` (inside this skill folder) that match the question, read them, and reason directly from their principles applied to the user's numbers and constraints.
- Never quote the playbook like a textbook. Talk like a sharp senior PPC strategist answering their exact decision in plain currency and concrete steps.
