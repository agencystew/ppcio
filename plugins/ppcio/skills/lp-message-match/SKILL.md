# Ad-to-Landing-Page Message Match

Compare what made the visitor click the ad with what greets them in the first 5 seconds on the landing page.

## Start here

- If a local `landing-pages/<site>/` folder exists for this business, read `ads.md`, `context.md`, and `inputs/site-page-text.md` (plus `inputs/site-page-text-phone.md` and screenshots if present). Otherwise work from the ad copy, search terms, and page copy/screenshots the user supplies.
- Reference `../landing-page/references/above-the-fold-and-message-match.md` for first-screen and awareness-stage continuity rules.

## Method

1. Identify the actual ad headline, description, search term, or campaign promise. Label any inferred search intent clearly as a guess; if the ad is missing, tighten the opening where you can and ask for the ad before claiming an ad mismatch.
2. Check alignment across all five seams: **promise/keyword scent**, **audience**, **offer/price**, **proof**, and **next step**. A page can repeat the keyword and still sell the wrong thing.
3. Quote both sides of each mismatch verbatim (ad line vs. first-screen line). Judge the first screen on mobile and desktop — an offer buried halfway down the page does not save a cold click.
4. Keep all prices, conditions, and brand language strictly true. Never make the page promise more than the business confirms. Never invent testimonials, guarantees, or "free" offers to make the match sound stronger.

## Output

1. State the single biggest mismatch in one plain sentence (quoting both sides).
2. Provide the paste-ready first-screen fix: **Headline**, **Supporting line**, **Proof line** (real proof nearby, or name what proof is missing), and **Button label**.
3. Give one short reason explaining why the change fixes the click-to-page drop-off. Keep under 150 words by default unless asked for a multi-ad-group breakdown.
