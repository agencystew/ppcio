# PPC.io for Claude

Everything PPC.io does, inside your own Claude: the landing page studio (audit, design, build, go live), 25 Google Ads skills, and a library of the best landing pages in 144 kinds of business.

## Start in 2 lines

In Claude Code (the Code tab in the Claude desktop app, or the terminal), type these 2 lines, one at a time:

    /plugin marketplace add https://github.com/agencystew/ppcio.git
    /plugin install ppcio@ppcio

Start a new chat. Then ask:

    what can PPC.io do for me?

Claude asks for your website and shows you the first 3 things a buyer notices on it, in about 2 minutes. Then it tells you what to do next.

If you bought the licence, paste your key into the chat at any time. It starts with `PPCIO-`.

## Other AI tools

PPC.io works best in Claude Code, which does the best design work. It also works in Codex, Cursor, Gemini CLI and other AI tools that can run commands. Paste this one line into your terminal:

    curl -fsSL https://raw.githubusercontent.com/agencystew/ppcio/main/install.sh | sh

It puts PPC.io in `~/.ppcio/kit`, adds its skills to each AI tool it finds, and gets the page checker ready. Then open your AI tool in any folder and ask "what can PPC.io do for me?". Run the same line again to update.

## What you need

Claude Code on a Mac or Linux. The first run installs what the page checks need (about 1 minute). Nothing else to set up.

## Updates

Type `/plugin`, open the Marketplaces tab, pick `ppcio` and turn on auto-update. Or ask Claude: "update PPC.io".

## Privacy

Everything runs on your computer, in your Claude. Nothing about your pages or your ads goes to PPC.io. With a licence, the full style library downloads once from PPC.io; that request carries only your key.
